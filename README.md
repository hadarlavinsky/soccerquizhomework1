# Pitchside ⚽ — A Soccer Fan Site

Pitchside is a static website built for my "AI Assisted Development of Products and Services" class (HW1). It's a small hub for soccer fans with an interactive positions explainer, a World Cup history timeline, and a trivia quiz.

## 🔗 Live Website

**[https://hadarlavinsky.github.io/soccerquizhomework1/](https://hadarlavinsky.github.io/soccerquizhomework1/)**

## What's in the site

- **Home** — an overview of the site and why I built it
- **Positions** — click markers on an interactive pitch diagram to learn what each position (GK, defenders, midfielders, forwards) does during a match
- **World Cup History** — a timeline of memorable moments from FIFA World Cup history
- **Trivia Quiz** — a short multiple-choice quiz that tracks your score

## About this project

This is a **static website** — it has no user logins and doesn't store any data between visits. It's built using only:

- `.html` files
- `.css` files
- `.js` (JavaScript) files

## Running it locally

1. Clone this repo:
   ```
   git clone https://github.com/hadarlavinsky/soccerquizhomework1.git
   cd soccerquizhomework1
   ```
2. Start a simple local web server:
   ```
   python3 -m http.server 8000
   ```
3. Open your browser to `http://localhost:8000`
