Why I Built This

I've been a soccer fan for years, and I wanted a simple site that brings together a few things I enjoy about the sport: understanding tactics and positions, appreciating the history of the World Cup, and a bit of friendly trivia to test what I know. This site was built as a class project using only HTML, CSS, and JavaScript — no server, database, or logins required.
